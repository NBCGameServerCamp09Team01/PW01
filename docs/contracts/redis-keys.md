# Redis 키 규칙

> 버전: v0 · 상태: 작성 전 · 사용: PW01WebServer

## 이름 규칙

- 형식: `pw01:<도메인>:<식별자>[:<하위>]` (TBD: 팀 확인)
- 소문자, 구분자는 `:`
- 만료(TTL)가 필요한 키는 반드시 TTL을 적습니다.
